# Task: Create problem sets for all 10 lectures

## Description

Create comprehensive problem sets (Problem Sets 1-9 plus final project) for the entire course. Each should have ~5-8 problems mixing conceptual, computational, and proof-based exercises.

**Target:** 10 problem sets total
- Problem Sets 1-9: Weekly assignments
- Final Project: Open-ended research or application

**Estimated effort:** ~10-15 days total (1-1.5 days per problem set)

## Acceptance Criteria

### Problem Set Structure
- [ ] 5-8 problems per set
- [ ] Mix of conceptual, computational, and proof problems
- [ ] Increasing difficulty within each set
- [ ] Clear connection to lecture material
- [ ] Solutions provided (for instructor)

### Specific Problem Sets
- [ ] PS1: Exponential families and Fisher information
- [ ] PS2: Axioms and submodularity
- [ ] PS3: Information relaxation and constrained flows
- [ ] PS4: Lagrangian mechanics and constraints
- [ ] PS5: Poisson brackets and Hamiltonian flow
- [ ] PS6: Perturbation analysis and tensor notation
- [ ] PS7: Symmetric/antisymmetric decomposition
- [ ] PS8: GENERIC framework applications
- [ ] PS9: Regime emergence and coexistence
- [ ] Final Project: Multiple options (research, application, computational)

## Implementation Notes

**Best practice:** Create problem sets as lectures are developed, not after.

**Approach:**
- Problems should reinforce key concepts
- Include computational exercises (Python/Jupyter)
- Some problems connect multiple lectures
- Advanced problems optional (marked with *)

**Final project options:**
- Apply framework to specific system
- Explore an open question
- Develop computational tool
- Write expository paper
- Extend theory in some direction

**Integration:**
- Part of Phase 5 (Course Materials Integration)
- But should be created alongside lectures
